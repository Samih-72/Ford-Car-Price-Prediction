# Ford Car Price Prediction

## Project Overview
This project predicts the selling price of Ford cars using Machine Learning.

## Dataset
The dataset contains information about Ford vehicles including:

- Model
- Year
- Transmission
- Mileage
- Fuel Type
- Tax
- MPG
- Engine Size
- Price

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Machine Learning Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. One-Hot Encoding
5. Feature Scaling
6. Model Training using Linear Regression
7. Model Evaluation

## Results

The model was trained to predict used Ford car prices based on vehicle specifications.
